# Source Project

Place your original project here.

> ⚠️ **READ-ONLY** — Do NOT modify any files in this folder.
> This folder is a reference only. All output goes to `../output/`.

## How to populate this folder

**Option A — Copy your project:**
```bash
cp -r /path/to/your/laravel-project/* ./source/
```

**Option B — Git submodule (recommended for large projects):**
```bash
git submodule add https://github.com/yourorg/your-project.git source
```

**Option C — Symlink:**
```bash
# Windows (run as admin)
mklink /D source C:\path\to\your\project

# Linux/Mac
ln -s /path/to/your/project source
```
