# Pattern Mapping: Ruby on Rails → Node.js (Express + Prisma + TypeScript)

## Application Layer

| Source (Rails) | Target (Node/Express) | Notes |
|----------------|----------------------|-------|
| `app/controllers/` | `src/controllers/` or `src/handlers/` | |
| `app/models/` | `src/models/` (Prisma schema) | |
| `app/services/` | `src/services/` | |
| `app/serializers/` | `src/dto/` or `src/transformers/` | |
| `app/helpers/` | `src/utils/` | |
| `app/mailers/` | `src/mailers/` | Nodemailer |
| `app/jobs/` | `src/workers/` | Bull/BullMQ |
| `app/policies/` | `src/middleware/auth.ts` | |
| `app/concerns/` | Mixins or utility functions | |
| `config/routes.rb` | `src/routes/` | Express Router |
| `config/initializers/` | `src/bootstrap/` | |
| `db/migrate/` | `prisma/migrations/` | Auto-generated by Prisma |
| `db/schema.rb` | `prisma/schema.prisma` | |
| `lib/tasks/` | `src/scripts/` | npm scripts or ts-node |
| `spec/` or `test/` | `src/__tests__/` or `tests/` | Jest |

## Routing

| Source (Rails) | Target (Express) | Notes |
|----------------|-----------------|-------|
| `get '/users', to: 'users#index'` | `router.get('/users', handler)` | |
| `post '/users', to: 'users#create'` | `router.post('/users', handler)` | |
| `put '/users/:id', to: 'users#update'` | `router.put('/users/:id', handler)` | |
| `delete '/users/:id', to: 'users#destroy'` | `router.delete('/users/:id', handler)` | |
| `resources :users` | Manual CRUD routes | |
| `namespace :api` | `router.use('/api', apiRouter)` | |
| `scope module: :v1` | `router.use('/v1', v1Router)` | |
| `before_action` | `router.use(middleware)` | |
| `params[:id]` | `req.params.id` | |
| `root to:` | `app.get('/', handler)` | |

## ORM (ActiveRecord → Prisma)

| Source (ActiveRecord) | Target (Prisma) | Notes |
|----------------------|-----------------|-------|
| `User.find(id)` | `prisma.user.findUnique({where: {id}})` | |
| `User.find_by(email:)` | `prisma.user.findFirst({where: {email}})` | |
| `User.all` | `prisma.user.findMany()` | |
| `User.where(active: true)` | `prisma.user.findMany({where: {active: true}})` | |
| `User.create(...)` | `prisma.user.create({data: ...})` | |
| `user.update(...)` | `prisma.user.update({where: {id}, data: ...})` | |
| `user.destroy` | `prisma.user.delete({where: {id}})` | |
| `User.includes(:posts)` | `include: {posts: true}` | |
| `User.joins(:posts)` | Prisma relations / raw SQL | |
| `User.order(:created_at)` | `orderBy: {createdAt: 'asc'}` | |
| `User.limit(10).offset(20)` | `take: 10, skip: 20` | |
| `User.count` | `prisma.user.count()` | |
| `scope :active` | `where: {active: true}` filter | |
| `belongs_to` | `@relation` in Prisma schema | |
| `has_many` | `@relation` (one-to-many) | |
| `has_many :through` | Many-to-many in Prisma | |
| `timestamps` | `createdAt DateTime @default(now())` | |
| `paranoia` (soft delete) | `deletedAt DateTime?` + filter | |

## Authentication

| Source (Rails/Devise) | Target (Node) | Notes |
|----------------------|---------------|-------|
| Devise | `passport.js` or `jsonwebtoken` | |
| `current_user` | `req.user` from middleware | |
| `authenticate_user!` | Auth middleware | |
| `bcrypt` | `bcryptjs` | |
| Session auth | JWT (`jsonwebtoken`) | |
| `devise_token_auth` | JWT middleware | |

## Validation

| Source (Rails) | Target (Node) | Notes |
|----------------|---------------|-------|
| `validates :name, presence: true` | `z.string().min(1)` (Zod) | |
| `validates :email, format:` | `z.string().email()` | |
| `validates :age, numericality:` | `z.number()` | |
| `validates :name, length:` | `z.string().min(2).max(100)` | |
| `validates :email, uniqueness:` | Custom validation + DB check | |
| `validate :custom_method` | Custom Zod refinement | |
| `before_validation` | Middleware or transform | |

## HTTP Response

| Source (Rails) | Target (Express) | Notes |
|----------------|-----------------|-------|
| `render json: data, status: 200` | `res.status(200).json(data)` | |
| `render json: data, status: :created` | `res.status(201).json(data)` | |
| `head :no_content` | `res.status(204).send()` | |
| `render json: { error: ... }, status: 422` | `res.status(422).json(...)` | |
| `render json: { error: ... }, status: 401` | `res.status(401).json(...)` | |
| `redirect_to` | `res.redirect(url)` | |
| ActiveModel Serializers | DTO class or plain function | |

## Testing

| Source (Rails/RSpec) | Target (Jest) | Notes |
|---------------------|---------------|-------|
| `describe` | `describe` | Same |
| `it` | `it` or `test` | Same |
| `before(:each)` | `beforeEach` | Same |
| `after(:each)` | `afterEach` | Same |
| `expect(...).to eq(...)` | `expect(...).toBe(...)` | |
| `expect(...).to be_truthy` | `expect(...).toBeTruthy()` | |
| `FactoryBot.create(:user)` | Test fixtures or `prisma.user.create()` | |
| `DatabaseCleaner` | DB cleanup in `afterEach` | |
| Request specs | `supertest` + Express app | |
| `allow(...).to receive` | `jest.mock()` | |
